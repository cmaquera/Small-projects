# Formularios PHP y AJAX

Ejemplos de procesamiento de formularios HTML mediante envío POST tradicional y peticiones asíncronas AJAX a scripts PHP (`accion.php` y `procesar_datos.php`).

## Prerrequisitos

- PHP 7.4 o superior (o PHP 8.x)

## Ejecución

Para ejecutar los scripts PHP y probar el procesamiento en tu máquina local:

```bash
# Desde la carpeta del proyecto
cd Formularios-PHP-Ajax
php -S localhost:8000
```

Luego abre tu navegador en `http://localhost:8000`.
