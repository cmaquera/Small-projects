# Database Game

A game built with Node.js + Express that stores player data in a MySQL database.

## Prerequisites

- Node.js
- MySQL running on `localhost:3306`
- A database named `juego_db` (user `root`, password `root` — configured in `app.js`)

## Run

```bash
npm install
node app.js
```

Then open `http://localhost:5000` (port is overridable via the `PORT` environment variable).
