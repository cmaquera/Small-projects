# Multiplayer Shoot Game

Juego multijugador 2D en tiempo real utilizando Canvas, Node.js y Socket.io. Los jugadores compiten apuntando y haciendo clic sobre los objetivos antes de que termine el tiempo.

## Prerrequisitos

- Node.js (v14 o superior)

## Instalación y Ejecución

1. Instalar dependencias:
   ```bash
   npm install
   ```

2. Iniciar el servidor:
   ```bash
   npm start
   ```

3. Abrir en el navegador:
   Abre una o más pestañas en `http://localhost:1337` para jugar en multijugador. Cada pestaña conectada representará a un jugador distinto en la pantalla.
